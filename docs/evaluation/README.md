# Tibetologist evaluation kit

Phase C of the scholarly roadmap (section 10): find out what actually interrupts
scholarly Tibetan writing before deciding which features to build.

The kit lives in the public playground so a participant and a facilitator can open
it beside the Writing Room: `playground/evaluate.html` (published at
https://ttime-ime.github.io/playground/evaluate.html). It holds the ground rules,
the task sheet, the 20-minute session script and the findings-log template. The
symbol catalogue review page is `playground/symbols.html`.

Edit the kit there, not here. After each session, complete the log, update the
ranked backlog, and record what to reject or defer.
