# Tibetologist evaluation kit

Phase C of the scholarly roadmap (section 10): find out what actually interrupts
scholarly Tibetan writing, before deciding which features to build.

| File | Use |
|---|---|
| [session-script.md](session-script.md) | What the facilitator says and does, minute by minute |
| [task-sheet.md](task-sheet.md) | The tasks the participant is given |
| [findings-log.md](findings-log.md) | Template for one session's observations and the running backlog |

The participant also needs two pages of the public playground:
the Writing Room (`index.html`) and the symbol review page (`symbols.html`).

## Ground rules

- Two or more sessions if collaborators are available, one with an experienced Tibetologist.
- Observe tasks; do not ask the participant to approve a feature list.
- Ask permission before keeping any sample text. Nothing is collected automatically.
- Separate what you saw from what you assume. Say what you would reject or defer.
- The playground is a web prototype. It is not the macOS input method, so do not
  judge the installed experience from it. The macOS build exists (release candidate
  signed and notarized) but has not been tested by a specialist.

## Before the session

1. Open the playground in the participant's usual browser. Check that Tibetan displays.
2. Have the participant's own current input method ready to show.
3. Prepare two or three difficult sequences from their field (ask in advance).
4. Print or open the task sheet. Start the findings log.

## After the session

Within a day: complete the findings log, update the ranked backlog, and write down
what you would **reject or defer**. File playground bugs as GitHub issues with the
participant's agreement.
