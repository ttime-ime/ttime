T-Time

T-Time is an experimental Tibetan input method. You type Tibetan in EWTS transliteration and it appears as Tibetan script, with a toolbar, a stacker for Sanskrit stacks and a table of symbols.

This installs T-Time.app into /Library/Input Methods for all users of this Mac. It needs an administrator password.

This is an early alpha. Please keep a copy of anything important you type with it.
