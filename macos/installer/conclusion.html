T-Time is installed

Two steps remain, because macOS does not let an installer turn on an input method:

  1. Log out and log back in, so macOS notices the new input method.
  2. Open System Settings › Keyboard › Text Input › Input Sources › Edit…, press +, find T-Time (EWTS) (under Tibetan or Others) and add it.

Then choose T-Time from the input menu in the menu bar and click into a text field.

To remove it: remove T-Time from Input Sources, then delete /Library/Input Methods/T-Time.app and log out and in again.
