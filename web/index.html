Editor

Type EWTS (Wylie). Highlighted text is provisional: it can still change as you type, and becomes fixed when you press space or Enter.

Limits. Typing is handled only at the end of the text. If you move the cursor into earlier text, typing there becomes ordinary browser editing (no EWTS). Backspace removes the last typed letter of the provisional run, then behaves normally. Not an IME, and no phone or dictionary features exist.

Examples

Each button replaces the text with a sample. Only the first group is ordinary; the last group shows unsettled questions that a specialist should rule on.
